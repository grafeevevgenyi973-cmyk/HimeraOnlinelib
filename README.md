# NTHMOD test starter

## Что проверяет этот тест
- Запускается автоматически при push/обновлении `NTHMOD.so` в корне репозитория.
- Проверяет, что файл существует и является ELF64 для AArch64.
- Сохраняет исходную библиотеку как GitHub Actions artifact без изменений.

## Что пока НЕ делает
Этот тест **не отключает** меню или рендер и не изменяет бинарник. Это намеренно:
автоматически вырезать неизвестные функции из stripped `.so` по одному имени файла
небезопасно и может повредить остальные функции мода.

## Как установить
1. Распакуй содержимое архива в корень репозитория HimeraOnlinelib.
2. Убедись, что библиотека называется ровно `NTHMOD.so` и лежит в корне.
3. Закоммить и отправь изменения в GitHub.
4. Открой вкладку Actions и проверь запуск `NTHMOD test pipeline`.
5. В успешном запуске скачай artifact `NTHMOD-validation-test`.

`src/NTHMOD_detector.cpp` — диагностическая заготовка для Android NDK.
Она определяет, загружена ли NTHMOD.so в процесс, но не вмешивается в рендер.
